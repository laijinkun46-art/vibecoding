# PROJECT_SPEC.md

## 一、项目概述

项目名称：
基于 DEM 与历史降雨数据的南宁洪水动态变化检测 WebGIS 系统

项目类型：本科 GIS 课程设计

研究区域：广西南宁邕江城区重点河段

历史事件：2024 年 9 月南宁洪水

## 二、研究目标

1. 获取真实 DEM、历史降雨和河流数据。
2. 实现地形与降雨数据的空间分析。
3. 构建简化洪水淹没情景模型。
4. 实现不同时刻洪水淹没范围变化检测。
5. 使用 CesiumJS 实现三维 WebGIS。
6. 使用 Three.js 实现河流动态效果。

## 三、最小数据集

### DEM

首选：FABDEM 30m
用途：
- 地形展示
- 高程分析
- 淹没计算

### 降雨

采用：CHM_PRE V2，中国大陆逐日 0.1° 格点降水
制作团队：北京师范大学团队；正式仓储版本固定为 V2.1.1
数据记录：https://doi.org/10.5281/zenodo.20378336
时间：产品日期标签 2024-09-06 至 2024-09-13，共 8 日
累计时段：每个标签日表示前一日北京时间 20:00 至当日 20:00；八日整体为 2024-09-05 20:00 至 2024-09-13 20:00，不能标为零点到零点。
数据性质：基于站点观测及协变量生成的格点估计产品，不是研究区逐点实测。
用途：
- 日尺度历史降雨过程
- 累计降雨统计
- 逐日降雨时间序列可视化

替换记录（2026-11-23）：原首选为 GPM IMERG Final V07，因当前无 NASA Earthdata 账号且用户接受日尺度并选择国内团队产品，改用 CHM_PRE V2。IMERG 检索记录保留作备选，不混入正式时间序列。国内制作团队不代表仓储服务器位于国内。

### 河流

首选：OpenStreetMap
用途：
- 邕江河流位置
- 河流连通性分析
- 水流动画

数据源不可用时允许替换，
但必须记录替换原因。

## 四、核心分析方法

### 1. DEM 地形分析

计算：
- 高程
- 坡度
- 地形阴影

### 2. 降雨时序分析

计算：
- 各时段降雨量
- 累计降雨量
- 降雨变化曲线

按 CHM_PRE 的 20:00—20:00 气象日解释日期；不将逐日数据插值后宣称具有小时或半小时观测精度。

### 3. 简化淹没分析

使用 DEM、河流连通性和指定水位情景，
计算淹没范围和水深。

必须检查 DEM 与水位的垂直基准。

### 4. 洪水变化检测

对比两个时间节点：

- 新增淹没区域
- 持续淹没区域
- 退水区域

输出变化面积和空间分布。

## 五、系统功能

1. 三维地图浏览
2. DEM 地形加载
3. 历史降雨可视化
4. 洪水时间轴播放
5. 洪水淹没范围展示
6. 两期变化检测
7. 淹没面积和水深统计
8. Three.js 河流动态效果

教学水动力扩展复用现有地图，在 AOI 内展示整条邕江、两岸湿区变化与模型流速。情景参数和适用范围见[全河段总规范](docs/YONGJIANG_HYDRODYNAMIC_SIMULATION_SPEC.md)。

## 六、技术架构

前端：Vue 3 + CesiumJS + Three.js + ECharts

后端：FastAPI

数据处理：Python GIS

第一版不使用数据库。

## 七、项目限制

- 可开展基于真实地形和假设参数的教学二维水动力情景，不要求工程级模拟或历史事件复现
- 不进行专业河床测量
- 不开展复杂流域产流率定
- 不要求实时洪水预报
- 不使用虚构历史数据
- 不追求工程级洪水模拟精度

## 八、验收标准

- 能运行完整 WebGIS 页面
- 能加载真实 DEM
- 能读取历史降雨
- 能显示邕江河流
- 能生成简化洪水淹没结果
- 能通过时间轴查看变化
- 能计算两期变化面积
- 能展示动态水流效果
- 能解释数据来源和算法局限
