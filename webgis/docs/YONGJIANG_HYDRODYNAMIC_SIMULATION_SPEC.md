# 研究区整条邕江河段洪水动态模拟总规范

版本：1.0 审阅稿。日期：2026年11月24日（北京时间）。

项目根目录：`C:\Users\ly5it\vibecoding\webgis`。

## 一 项目目标

在现有 WebGIS 中，以研究区内整条邕江河段及两岸地形为范围，构建教学用二维水动力情景，展示水流传播、水面上涨、漫岸扩散和退水。最终画面应流畅、连贯，能够暂停、拖动时间轴、调整播放倍率并查询水深和流速。

保留真实 DEM 和现有河流位置，允许缺失的河床、水文及摩阻参数采用明确标注的模拟值。无需收集研究区外的上游流域资料，不以取得真实流量、水位或历史验证资料作为启动演示的前提。

对外统一表述为“基于真实地形和假设参数的洪水动态情景模拟”。不声称精确复现2024年洪水，不将模拟参数和模型结果标作实测资料。

全河段覆盖、允许模拟参数和优先保证动态效果，是实施和验收的目标。模型、效果和性能以各阶段的实际验收记录为准。

## 三 后续约束的归档方式

每次新增一组文档约束，在项目 `docs/` 下新建一个文件。采用 `CONSTRAINT_<主题或阶段>_<YYYYMMDD>.md` 命名。同一主题同日有多份时，另加序号。每份文件记录标题、版本、日期、状态、适用范围和约束正文。

每份新增约束文件应声明以下关系，并用相对链接指向相关文件：

- **上位文档（被包含于）**。覆盖整个水动力扩展的约束挂到本总规范。只针对某一阶段的约束，优先挂到该阶段已有的约束文件或实施细则。
- **下位文档（包含）**。有进一步细化的约束时，列出相关文件及各自范围。没有下位文档时，记为“暂无”。
- **关联文档（参考）**。列出提供背景、技术方案或验证证据的文件。
- **替代条款（如适用）**。注明被替代文件、章节、旧条款和新适用范围。其他条款继续按各自文档执行。

新文件中的上位链接用于追溯包含关系。需要汇总多个子文件时，可另建独立索引。当前已包含的实施细则见第二节，后续专题或阶段约束由新增文件声明各自的上位关系。
