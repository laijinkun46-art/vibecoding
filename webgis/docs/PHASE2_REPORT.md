## DEM 与河流方法

原生裁剪保留 FABDEM 像元值。计算坡度需要米制水平距离，因此另生成 WGS84 / UTM 49N（EPSG:32649）30 m 网格，采用双线性重投影。该网格便于计算，不提高原始数据精度。原始高程仍为文档所述 EGM2008（EPSG:3855），本阶段不转换垂直基准。

研究区边界在经纬度空间按不超过0.001°加密后投影，按像元中心生成计算区掩膜。地形有效像元318,721个，网格为457行×728列，有效高程63.00—288.07 m。像元计数对应投影平面面积286.8489 km²；Phase 0 椭球面积约286.5479 km²，差约0.105%，包含投影尺度与边界栅格离散影响，不能把两种面积当成完全相同的量。后续以30 m网格统计面积时必须说明这一口径。

坡度采用 Horn 方法，地形阴影采用同一米制网格。未向3×3邻域缺失或边缘外推，因此它们的有效范围略小于 DEM。河流只做真实几何裁剪与坐标转换，不吸附或补绘缺失连接。当前邕江与朝阳溪仍为两个几何连通分量；邕江主线栅格为单个八邻域连通分量。栅格化采用 ALL_TOUCHED（线触及的所有像元）且限制在有效 DEM 内，它表示连通分析的候选种子，不表示河宽、水下河床或淹没区域。

## 降雨方法与结果

不将0.1°降雨重采样成30 m。完整保留六个源格点，逐日与累计栅格仍为2×3。单元范围为中心点向四周各0.05°。每个单元与研究区求交，转换到等积坐标系EPSG:6933计算面积；权重为交叠面积除以计算区面积。每日面平均为各格点值乘权重之和，六个权重之和经检查为1。

原始单位为mm/day；每条记录对应完整24小时，数值用于该日累计量mm。日期标签2024-09-06至09-13，整体时段为北京时间2024-09-05 20:00至09-13 20:00，不是零点到零点。
