CRS 是坐标参考系，用来说明数据如何对应地球位置。候选计算域继续使用米制 EPSG:32649；高程按既有 EGM2008 基准解释，不能直接当作水文站水尺读数。

先核对 JSON 内保存的 SHA256 文件指纹与实际输入、输出是否一致，再检查图层要素数量、几何有效性和 DEM 覆盖。最后在 QGIS 等 GIS 软件中叠加现有 DEM、AOI、河线、候选域和边界，查看整体位置及局部细节。

重点检查：

1. 候选域是否包含连续河段和两侧待评估的洪泛地形，是否存在 NoData 空洞。
2. 端界是否被相邻弯道影响，是否遗漏可能的出流或侧向来流通路。
3. 侧界低口是否可能截断洪泛通道；不能仅因边界高程较高就设为封闭墙。
4. 河线与实际主槽的位置是否有明显偏差，支流缺口是否影响选域。
5. 纵横剖面是否保留原 DEM 精度和缺测信息，是否把地表高程误写成实测河床。

完整主线纵剖面的63m平台不能直接用于确定实际流向、河床坡降或水深。A/B是端界编号，L/R是相对几何里程方向的侧别，均不自动代表水文角色。

## 六 进入 Phase 4.1.2 的条件与任务

计算域确认后，下一阶段只准备所选范围的水动力地形：检查 DEM 有效覆盖、局部异常、纵横剖面及高程基准，生成独立的局部派生 DEM，不覆盖原始或 Phase 2 DEM。

FABDEM不能直接当作可靠水下河床。河床宽度、深度、纵坡等参数需独立记录依据和假设，确认处理方案后再生成参数化地形，不预先挖深河道。

Phase 4.1.2 不包含安装求解器、运行洪水模拟或修改前端。后续降雨转换、糙率与边界参数、网格准备按各阶段分别推进。
