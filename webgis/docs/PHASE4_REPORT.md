日期：2026-11-23。用户确认继续后完成河流、假设淹没、两期变化、情景顺序播放和图表。真实DEM沿用此前实现，本轮不进入Phase 5。

## 操作

打开本机[地图页面](http://127.0.0.1:5173/)。前后端启动方法见README，本轮保留既有5173与8000服务供用户查看。

- 默认显示S01、75m假设水位的蓝色淹没水面和当前OSM河流中心线，背景为真实DEM与在线卫星影像。
- “假设水位”下拉框、底部滑杆和四个情景按钮可切换75、80、85、78m情景，面积和差值水深同步更新。
- “播放”按S01至S04的顺序前进，每个已加载情景停留约3.5秒，最后自动结束。可以暂停；在末尾点击“重新播放”返回S01。手动选择情景会停止播放。
- 该时间轴表示假设情景顺序，不表示2024年真实日期、传播速度或退水历时。CHM_PRE降雨图独立保留真实产品日期。
- “两期变化”切换三组比较，用青色/蓝色/橙色表示新增/持续/退水。左侧列出各类面积。
- 淹没水面/变化分类与河流中心线可分别开关。“查看淹没范围”返回邕江中段，“查看地形近景”返回青秀山，“定位全研究区”返回完整计算区。
- ECharts提供四情景面积图、真实逐日及累计降雨图；折叠表格保留可读数值。累计研究区面平均降雨为137.43mm，日期仍为前一日20时至当日20时。

## 数据与渲染

新增的`export_web_layers.py`只对Phase 2/3已验收JSON和GeoJSON去除排版空白，不简化坐标、删除孔洞、改变分类或重新计算面积。10个网页数据文件加清单共约3.39MiB，位于`frontend/public/analysis/`；逐项解析后与源对象完全相同。浏览器校验每份数据的SHA256，异常时显示错误，不返回伪造默认统计。

Cesium GeoJsonDataSource加载实际淹没多边形，水面使用该情景的固定高程，变化分类贴地展示。显示网格约330m的角度细分用于减小长三角形与地球曲面的弦高差，不改变30m分析范围或计算精度。数据源按情景缓存，只显示当前图层；异步请求用版本号排除过期结果。河流为当前OSM中心线，保留OSM/ODbL标注。

地图的DEM和水面沿用同一EGM2008源数值作近似三维展示，仍未转换为准确椭球高。DEM原生网格与30m分析网格的插值差异可能使水面边缘局部遮挡。显示不能用于精密水位量测；统计始终使用Phase 3原始分析成果。范围外地形、实测河床及精细堤防等限制不因可视化消失。

用户明确授权后新增ECharts 6.1.0，仅修改本项目前端依赖与锁文件，采用按需导入柱状图、折线图、坐标轴、图例和提示组件。未新增数据库、服务框架或Three.js。

## 复现

已有数据和前端依赖无需每次重装。需要从分析成果重新导出网页资源时，在项目根目录PowerShell执行：

```powershell
$env:PATH = 'D:\Arcgis10.8.2\bin;' + $env:PATH
$env:GDAL_DATA = 'D:\Arcgis10.8.2\apps\gdal\share\gdal'
$env:PYTHONIOENCODING = 'utf-8'
& 'D:\Arcgis10.8.2\apps\Python312\python.exe' '.\scripts\export_web_layers.py'
node '.\scripts\verify_phase4.mjs'
npm.cmd run build --prefix frontend
```

JavaScript资源检查要求5173前端服务运行。Vite构建会复制public内的资源，不要求构建机安装GDAL。后端基础API不承担GIS计算，本轮无须给后端虚拟环境安装NumPy或ECharts。
