# AGENTS.md

## 1. 项目身份

本项目是本科 GIS 课程设计。

项目名称：
基于 DEM 与历史降雨数据的南宁洪水动态变化检测 WebGIS 系统。

研究区域：广西南宁市邕江城区重点河段。

历史事件：2024 年 9 月南宁洪水。

核心目标：
利用真实 DEM、历史降雨和河流数据，实现洪水淹没情景分析、动态变化检测和三维 WebGIS 可视化。

项目以课程设计可完成、可运行、可解释为原则，不追求工程级洪水预报精度。

每次开始任务前，必须：

前端：
- Vue 3
- Vite

- Three.js
- ECharts

后端：
- Python
- FastAPI

GIS 数据处理：
- Rasterio

- Xarray

数据格式：
- GeoTIFF

- CSV
- JSON
- NetCDF/HDF5（视数据源而定）

不要随意增加数据库、微服务或复杂框架。

## 4. 数据规范

核心数据仅保留：

1. DEM 高程
2. 历史降雨
3. 河流矢量

优先寻找国内公开、易下载的数据源。

国外数据源作为补充。

数据必须：
- 来源真实且可追溯
- 记录下载地址和版本
- 检查坐标参考系
- 检查空间与时间覆盖
- 检查单位和缺失值
- 原始文件不得修改

禁止：
- 虚构历史数据
- 虚构下载成功
- 将演示数据冒充实测数据
- 通过重采样虚构精度
- 绕过登录验证或访问限制

下载大文件前报告预计大小。

## 5. 洪水分析规范

核心分析功能：

1. DEM 地形处理
2. 历史降雨时序分析
3. 简化洪水淹没情景分析
4. 两期淹没范围变化检测
5. 淹没面积与水深统计

采用 DEM + 河流连通性约束的简化淹没分析。

历史降雨与模拟水位之间的关系必须明确说明。

没有经过验证的水文模型时，不得声称降雨直接精确决定洪水水位。

不得将简化情景模拟描述为真实洪水预报。

## 6. 三维可视化规范

CesiumJS 负责：
- 三维地图
- DEM 地形
- 河流和洪水图层
- 淹没范围
- 时间轴

Three.js 负责：
- 河流水流动画
- 水面波纹
- 视觉特效

Three.js 不参与洪水物理计算。

优先使用 Cesium 原生能力。
仅在必要时集成 Three.js。
